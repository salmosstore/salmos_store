# SALMOS V22

Ver **ACTUALIZAR_V22.txt** para actualizar el Worker y la tienda, instalar
Administración en el celular y usar las opciones de destino y medidas.

Esta versión incluye las correcciones de V21: modo claro y banner,
cabecera unida, domicilio/sucursal, planchas mixtas, compras plegables,
recargos porcentuales o en pesos y detalles de transferencias.

Agrega la renovación del CP al cambiar de dirección, galerías horizontales
plegables con SALMOS primero y múltiples medidas por diseño sin duplicar
su imagen. Producción conserva y calcula con la opción elegida.

El listado real de sucursales y las tarifas comerciales dependen de la
configuración y los permisos de Correo Argentino. No se incluyen sucursales
ficticias ni se cambian las credenciales existentes.

No ejecutar schema.sql ni seed.sql sobre la base de datos en uso.
